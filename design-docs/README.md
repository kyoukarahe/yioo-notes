# Yioo Notes Design Docs

This folder owns forward-looking design guidance, current design audits, and
design research for `yioo-notes`.

Historical Phase 9 design files remain under `docs/` because they are part of
the implementation log. New design work should add or update files here.

## Files

- `design-guidelines.md`: current design operating rules and verification gates.
- `current-design-evaluation-2026-06-28.md`: current production design audit.
- `design-advancement-research-2026-06-28.md`: research and improvement
  directions to review before the next design implementation.

## Required Rule

Every design verification must include mobile and desktop checks. Mobile
verification is required even when a change appears to be CSS-only.
