Use `Card Details → Print Materials` to change the card stock and relief. These settings show the visual characteristics of print materials on screen. Check a print shop’s samples for the actual feel and finished result.

[Open SSR Card Maker](https://yioo.link/tools/en/image/ssr-card-maker/) · [Getting started](/notes/2026-09-23-ssr-card-maker-guide-en/)

In each close-up comparison, switch between **Before / After** to inspect the same area. Full-card images appear below. Select an image to view the whole card at a larger size.

The white, black, blue, and gray core stocks, along with white underprint, show only subtle changes in this example. In the close-ups, compare the brightness of the red clothing and the edges of its folds. For linen, look for fine grain across broad areas.

In these tables, **Before means the card before the effect being compared was applied**. The card already contains the uploaded artwork, frame, and text. Every example uses the same character and background, custom frame, `Karahe` title, and bottom caption. Layout, font, lighting, and angle stay the same within each table. To make differences easier to see, unrelated effects were disabled, and card stock, white underprint, and relief strength were all captured at 100%. No additional color correction was applied.

## Emboss / Deboss

**Embossing makes a surface appear raised; debossing makes it appear recessed.** Even with the same pattern, the arrangement of lit and shaded faces changes. Here, those differences are represented through shading and reflections on screen.

Switch between **No relief / Emboss / Deboss** in the close-ups to compare shading in the same area. For the basic patterns, look at surface contours; for the alpha patterns, focus on the character’s outline. The full-card images below show the pattern’s coverage and overall appearance.

In the editor, choose an emboss or deboss type, then select a `Relief pattern`. The full-card tables below run **No relief → Emboss → Deboss**. ‘No relief’ means relief is disabled; it is different from the pattern option named ‘Original’.

The current options are divided into blind and registered types, shown in separate tables below. Registered types have a stronger relief response and different gloss settings than blind types. **To follow the character’s shape, also select one of the alpha patterns described later.**

Following the settings saved in this card, relief is applied to the **character and frame**. The background and text are excluded.

### Adjusting relief

- **Strength**: adjusts the relief response. The comparisons above use 100%; the editor’s default is 60%.
- **Bevel width**: the width over which height changes along the edges of a character alpha pattern. A wider value makes the slope gentler; a smaller value concentrates the change in a narrower area. The comparisons use the project’s saved value of 13px; the editor’s default is 8px.
- **Outline width**: the width of the character’s inner-outline pattern. The comparisons use the default of 18px.
- **Application area**: chooses which parts receive the effect: Character, Background, Frame, or Text. If you upload artwork with a combined background into the Character slot, the entire file counts as the character target.
- **View effect only / Show areas**: lets you inspect the effect separately from the artwork or check its coverage. Both views were disabled for the comparison images above.

If the differences are hard to see in small images, enlarge them or slowly tilt the card in the editor. The most visible details change with the pattern direction and lighting angle.
